# Security

Please report security problems privately through GitHub: open the [Security tab](https://github.com/Abulkosim/tonearm/security) and click "Report a vulnerability". Don't open a public issue.

Include the Tonearm and macOS versions and steps to reproduce. You should get a reply within a week.

Only the latest release gets fixes. Tonearm updates itself, so most people get a fix within a day of its release.

Problems with the update channel or release signing count as security problems too, for example a way to make Tonearm install a build that didn't come from this repository's release workflow.
