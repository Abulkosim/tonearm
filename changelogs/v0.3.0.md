# v0.3.0

2026-11-11 · [Download](https://github.com/Abulkosim/tonearm/releases/tag/v0.3.0)

- Tonearm now updates itself. It checks once a day, downloads new versions in the background and installs them the next time its window is closed. Settings has a "Check for Updates…" button and a switch to turn daily checks off.
- Every version is now signed with the same certificate, so macOS keeps the permission to control Spotify after an update.
- Coming from v0.2.0: it cannot update itself, so install this version by hand once. macOS asks one last time for permission to control Spotify.
- A stable download link that always points to the newest version: https://github.com/Abulkosim/tonearm/releases/latest/download/Tonearm.dmg
- Install with Homebrew: `brew install --cask abulkosim/tap/tonearm`.
- A welcome window on first launch shows where Tonearm is in the menu bar. Opening Tonearm.app again while it runs now opens the player.
- The window always opens on the player, not on settings.
- Shows "Starting Spotify…" or "Connecting to Spotify…" instead of "Spotify isn't running" while Spotify starts.
- ⌃⌥P starts Spotify and plays if Spotify isn't running.
- Song-change notifications now show while Tonearm is in front, and clicking one opens Spotify. If macOS blocks them, settings says so and links to System Settings.
- Fixed Spotify sometimes reopening after you quit it while paused.
- Tonearm no longer asks Spotify for its state every few seconds when nothing is playing.
- The paused position now matches Spotify exactly.
- Fixed the progress bar freezing when Spotify stopped during a drag, and clicking it when a track has no length.
- Keyboard shortcuts keep working after the window is closed and opened again.
- Tooltips on every icon button, a keyboard focus ring that matches the player, and cleaner settings.
- The default menu bar title is shorter (24 characters), so it is less likely to be hidden behind the notch.
